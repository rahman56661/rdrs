# Submission checklist (from the build guide)
- [ ] Git repo on GitHub (code + README). `git init`, commit, push. **No secrets in the repo.**
- [ ] Architecture diagram: the Mermaid diagram in README.md (or screenshot it).
- [ ] Screenshots / screen recording of the Section 15 attack: dashboard Normal -> Warning -> Critical + incident table.
- [ ] Sample output: `data/reports/incident_1.*` and `logs/*.log` from your detection run.
- [ ] One-page write-up: `docs/WRITEUP.md` (add your name, tweak the wording).
- [ ] `pytest --cov=app` screenshot (coverage >= 90%).
- [ ] `docker compose up --build` screenshot (if Docker is available).
